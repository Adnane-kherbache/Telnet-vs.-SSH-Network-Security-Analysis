# Telnet vs SSH: Network Security Analysis & Machine Learning Classification

This project analyzes the fundamental differences between **Telnet** (unencrypted clear-text protocol) and **SSH** (encrypted protocol) 
through local network traffic capture and uses **Machine Learning (ML)** models 
to automatically classify network sessions based on extracted flow metrics.
